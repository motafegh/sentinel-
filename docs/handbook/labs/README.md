# Labs — supplementary practice layer

These labs are retained as hands-on exercises. They are **not current-state or release-readiness authority**.

Some labs intentionally exercise historical compatibility seams such as DATA v1, Run12, retained proxy artifacts, or older service mechanics. Before running a lab, check [`../16_current_status.md`](../16_current_status.md) and its owning canonical handbook chapter.

Current rules that override older lab wording:

- unknown/masked DATA vNext cells must never be filled with historical binary zero;
- current R4 threshold-fit, calibration-fit, and untouched-acceptance roles are unsupported/empty;
- audit MCP is read-only;
- V3 is the current registry submission protocol and signing/broadcast is outside the analysis MCP;
- no lab result by itself proves repaired-model quality or production readiness.

Labs may still be useful for mechanics, failure injection, source reading, and local verification when their prerequisites remain valid.
